# Magic Mermaid Quest 🧜‍♀️

A gentle, no-fail underwater collecting game for young children. Swim
through five pastel reef worlds, open glowing clams, gather pearls and
sea stars, and make fish friends who follow you.

**Play / install:** https://jamesawilson1901.github.io/magic-mermaid-quest/

On a phone, open the link and use *Add to Home Screen* (iPhone Safari:
Share → Add to Home Screen; Android Chrome: menu → Install app). It
installs with its own icon, runs fullscreen in landscape, and works
offline after the first play.

## How to play

- **Move**: hold a finger (or mouse) where you want to swim, or use the
  arrow keys / WASD
- **Song of the Tide** (music button / Space): opens every clam nearby
- **Sparkle Tail Spin** (swirl button / X): pulls pearls and stars to you
- Follow the sparkle trail to the next clam; collect every pearl to
  finish a level — or just keep swimming, nothing bad can ever happen

## About this repo

This is the built, deployable game only. The source asset packs and the
asset pipeline that generates `assets/` live in the (private) My-Games
repository under `magic-mermaid-quest/`. Deployment to GitHub Pages
happens automatically on every push to `main`.
